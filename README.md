# PDS2-2026-PF-grupo12

Integrantes do Grupo: Bernardo Amaral Lima, Caetano Salomon Nunes, Murilo Marciel, Rafael Estevão Silva Cunha.

Descrição Inicial do Problema: O intuito dessa aplicação é o de criar um livro de receitas digital que pode ser usado pelo usuário para adicionar, pesquisar e organizar receitas proprias ou de outros usuários à gosto, usando os conhecimentos básicos de c++ aprendidos nas aulas de PDS2.

Motivação da escolha: Ao analisar os possíveis temas, a idéia de um Ricettario parecia conter a oportunidade de aplicar de maneira simples e direta muitos dos conceitos explorados nas aulas de PD2. A imagem de como os diferentes módulos performariam suas diferentes funções em conjunto veio com mais facilidade para este tema do que para os outros quando discutida pelo grupo, e o próprio conceito de um livro de receitas é mais facil de abstrair quando se tem como referência os livros de receitas fisicos que podemos encontrar/interagir com em nosso cotidiano. Esses fatores combinados guiaram a escolha de tema do nosso grupo.
